# Meu Consultório — protótipo UX (Sprint 2)

Este repositório contém **somente um protótipo visual navegável**, destinado a avaliar a experiência de uso em celulares e computadores.

## Como abrir
- Abra o arquivo [index.html](./index.html) em um navegador, ou configure GitHub Pages para publicar a demonstração.
- Explore **Início, Agenda, Pacientes, Financeiro, Relatórios e Ajustes**.
- Marque sessões realizadas, teste faltas/cancelamentos e simule pagamentos.

## Aviso importante
- **Todos os pacientes e lançamentos são fictícios.**
- Não há login real, banco de dados, Google Calendar ou integração bancária.
- Os dados são mantidos apenas na memória da página; recarregar reinicia as simulações.
- **Não registre pacientes ou dados reais neste protótipo público.** A versão funcional exigirá autenticação, permissões de backend, armazenamento seguro e conformidade com a LGPD.

## Identidade
Roxo como cor principal, detalhes em laranja. Aplicativo planejado para uso exclusivo do profissional.
